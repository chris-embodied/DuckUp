# 小鸭小鸭，看看我在哪里

下载仓库或解压 GitHub 的源码 ZIP，双击本目录的 [index.html](index.html)。零依赖，可断网使用。在 GitHub 文件列表点 HTML 会看到源码，本地浏览器打开即可玩。

1. 选「正后方」，点「小鸭小鸭」。黄色小人一开始在头部扇形视野以外。
2. 看鸭子先转头、再原地转身。发现人的瞬间暂停，然后拖进度条，看身体怎样追上目标方向。
3. 选「空场」再试。观察它找不到人时会不会一直转下去。

这是一段基于现有桌面互动代码的二维回放。按键触发唤醒，语音、真人摄像头和舵机均未接入。模型时间与播放速度独立；空场大约 35 秒模型时间后停止。首页的物理仿真录像来自另一次带步态策略的试验，两个演示的观测频率与时间不能直接比较。

## 改一条规则

`engine.py` 中的 `Duck.tick` 根据可见性、头部方向和身体方向推进阶段。可以试试让鸭子多观察一会儿，比较正后方和空场的耗时。在仓库根目录运行以下命令，然后刷新本地页面。

```sh
python3 -B -m unittest discover -s examples/find-me
python3 -B examples/find-me/build.py
```

生成的页面内嵌四条轨迹，浏览器会直接播放。测试覆盖正后方、丢失目标、多个人进入、超时和方向变化速度。想提交新玩法，请带一个能成功的场景，也带一个它应该停下的场景。
