# 给调好的机械鸭安装 DuckUp

适用于 Radxa ZERO 3W、飞特 HD1910 × 15 和配套 HAT。准备 Mac、读卡器和 iOS 17 或更新版本的 iPhone。**一张 microSD 就够，有备用卡也可以用。**

### 1. 刷卡前，在 Mac 上留下标定

趁原系统还在，确认鸭子能正常 HOME 和卸力。让鸭子保持卸力，Mac 连同一网络，双击 [安装助手.command](../image/安装助手.command)，选 **1**，输入原中控显示的鸭子 IP。助手通过 SSH 读取驱动正在使用的标定，检查 15 个关节及 IMU 安装方向，并在访达中选中已读回核对的备份。如果已有这只鸭子经验证的实机标定，确认 TOML 文件已保存在 Mac 上即可。

| 你手里的卡 | 刷之前怎么做 | 日后怎么回到原系统 |
| --- | --- | --- |
| **只有一张，重刷原卡** | 写入会清空所有分区。确认标定备份在 Mac 上能读到，另存照片、自定义动作、模型等想保留的文件。想完整回退时，先正常关机、取卡，用读卡器将**整张卡**备份为镜像到 Mac，并校验备份。 | 把刷前备份的整卡镜像写回这张卡。单独的标定 TOML 只保存关节和 IMU 标定，无法还原旧系统、程序和个人文件。 |
| **有备用卡** | 导出标定后，收好原卡，只把可清空的备用卡插进读卡器。 | 正常关机断电，换回原卡。 |

如果这只鸭子的标定还只存在原卡上，请先完成备份，再打开刷卡工具。V260 随包样本不能代替实机零位。安装助手负责导出标定和配网，整卡备份及写镜像由你选用的磁盘工具完成。

### 2. 刷入镜像并配网

1. 将鸭子正常关机、断电。把要刷的卡插入读卡器，在 Etcher 中核对目标和容量，写入 **duck-base-zero3w-motion-v1.img** 或其 **.img.xz**，等待写后校验完成。[从本地 V260 原包构建同版镜像](../image/README.md)
2. 重新插入读卡器。Mac 如提示无法读取 Linux 分区，选「忽略」。双击安装助手，选 **2**。它会找到带遥控镜像标记的配置卷，显示卷名，请你选择刚才那份标定。填一次家庭 Wi-Fi 名称和密码即可。已装本次用于签名 App 的 Xcode，可直接用它随附的 Python 运行助手。
3. Mac 会打开这张卡专属的**遥控钥匙二维码**。让窗口保持打开。正常推出卡片，将鸭子关机断电，插入刷好的卡后上电。二维码和回执只留给机主，回执中还存有设备的管理员凭据。

DuckUp 第一次启动会导入原标定和这张卡独立的遥控钥匙，随后清除卡上待导入的个人配置。关节 ID 保存在舵机里，重刷系统也无需重写 ID。DuckUp 使用 V260 的运动模型，原系统自行切换的步态、表情参数和系统设置不属于标定迁移范围。

### 3. 在 iPhone 上接管

当前候选版需用 Xcode 在自己的 iPhone 上签名安装一次。[鸭控台安装说明](https://github.com/chris-embodied/duckup-control/blob/main/apps/ios/README.md)

1. 打开「设备」选当前镜像广播的蓝牙设备 **Duck Base**，首次输入观察码 **000000**。先打开「观察」，看 15 颗舵机是否都有反馈、倾斜方向是否与实物一致。高清摄像头需要 iPhone 与鸭子在同一 Wi-Fi。
2. 回到「设备」，点 **扫描遥控钥匙**，扫 Mac 上的二维码。App 会和当前鸭子核对钥匙，成功后可打开「遥控」。这部 iPhone 以后会自动使用已保存的钥匙。若二维码已关，可从本次 Mac 回执重新打开 `duck-home-qr.png`。如果手机不方便扫码，把同目录的 `duck-home.key` 保存到 iPhone「文件」，然后点 **从文件导入** 即可。
3. 扶正、托稳机身，先试 **准备站姿（HOME）** 和 **卸力**，确认关节确实放松。再次 HOME 并等站稳后，再点 **开始遥控**，小幅推前进或转向。如需回退，按第 1 步表格中对应的方式恢复。

| 遇到的情况 | 处理方法 |
| --- | --- |
| 助手找不到遥控卡 | 核对文件名中有 `motion`，并在写卡校验后重新插入读卡器。多张遥控卡同时出现时，只连接本次要配置的卡。 |
| 助手说标定未完成 | 核对是否从这只鸭子正在使用的驱动导出。回原系统补全缺失项。 |
| 已配对，只能观察 | 在设备页导入本次制卡回执里的钥匙。若只准备了观察镜像或没有迁移标定，设备不会提供完整遥控。 |
| 允许遥控，但 HOME 未就绪 | 在「观察」核对 15 颗舵机、IMU 和机身朝向，确认当前已卸力。 |
| 蓝牙有状态，摄像头只有模糊预览 | 给 App 本地网络权限，让 iPhone 和鸭子连同一 Wi-Fi，再看镜头前是否有新画面。 |
